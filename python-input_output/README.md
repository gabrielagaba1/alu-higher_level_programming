# python-input_output

This directory contains exercises on Python file input/output:
reading and writing text files, working with JSON serialization and
deserialization, and using the `pickle`-free JSON approach to
persist Python objects to disk.

## Tasks

| File | Description |
| --- | --- |
| `0-read_file.py` | Reads a UTF8 text file and prints it to stdout. |
