# SQL_introduction

This directory contains introductory SQL exercises: connecting to a
MySQL server, listing and creating databases, and running basic
queries from `.sql` scripts.

## Tasks

| File | Description |
| --- | --- |
| `0-list_databases.sql` | Lists all databases of the MySQL server. |
